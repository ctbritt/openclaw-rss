# Changelog

## 0.1.1

- Runs on OpenClaw 2026.11.3 stable and later (previously required 2026.11.5-beta.3).
- Decision-model grading no longer sends a request priority hint, which 2026.11.3 does not support.

## 0.1.0 — Initial release candidate

- Native theme-aware RSS/Atom reader with folders, unread and saved state.
- Feed discovery, conditional refresh, OPML import/export, and keyboard navigation.
- Search, exclusions, saved searches, and mute rules.
- Sanitized article display, full-text extraction, and full-text/summary toggle.
- Optional AI importance grading, model selection, and importance/spam filters.
- Agent conversation actions and three read-only library tools.
- Guarded network fetching and bounded article responses.
